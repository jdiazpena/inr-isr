The current project state is approximately this:
1.	There is a real 3D radar INR pipeline that uses real AMISR-like radar data.
2.	There is a synthetic 3D pipeline that was created to mirror the real 3D trainer as closely as possible, while replacing the data source with synthetic plasma data.
3.	The synthetic case uses sparse fake radar samples from a known analytic truth field, so we can evaluate the trained network against the full true field, not only at measured points.
4.	The important trainer is synthetic_train_3d.py.
5.	The trainer supports data loss plus optional curvature regularization.
6.	The current regularization form is based on second derivatives of the network output f(x,y,t) = log10(Ne):
o	spatial curvature terms involving fxx, fxy, fyy
o	temporal curvature term involving ftt
7.	The current reference run uses reference-ratio regularization with:
o	target_xy_ratio = 0.30
o	target_t_ratio = 0.30
8.	The current synthetic case is a high-amplitude moving Gaussian-like electron-density structure on a 500 km by 500 km domain.
9.	We are using a 31-time-record window, similar to a short real radar window.
10.	The network is currently fast enough that these tests are feasible; this is not intended to be a days-long run over huge datasets.
