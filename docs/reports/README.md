# Portable Reports

This directory contains the reports needed to understand the scientific reasoning
without access to the original Windows workspace.

## ISR/INR Research Plan

- `inr_isr_research_plan.pdf`: compiled research plan.
- `inr_isr_research_plan.tex`: LaTeX source.

## Synthetic Pilot Results

The `inr_synthetic_pilot_results/` directory contains:

- the compiled 25-page PDF;
- the complete LaTeX source;
- `make_results_figures.py`;
- every PNG referenced by the LaTeX document under `figures/`.

The report can be read and rebuilt from these Linux-local files. Historical Windows
paths in `../CODEX_CONVERSATION_EXPORT.md` describe the old session only and are not
dependencies.
